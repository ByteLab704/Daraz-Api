# 🛒 Daraz Search API

A lightweight, asynchronous REST API built with **FastAPI** and **Playwright** (Chromium) to dynamically extract live product search data and details from Daraz. Designed for easy containerization using **Docker**.

---

## ✨ Features

- ⚡ **High Performance:** Powered by FastAPI for quick async request handling.
- 🎭 **Headless Scraping:** Utilizes Playwright + Chromium to render dynamic JavaScript content seamlessly.
- 🐳 **Dockerized:** Fully containerized with custom memory-optimized browser flags.
- 📖 **Interactive API Docs:** Built-in Swagger UI and ReDoc for easy API testing.

---

## 🛠️ Tech Stack

- **Framework:** [FastAPI](https://fastapi.tiangolo.com/)
- **Browser Automation:** [Playwright (Python)](https://playwright.dev/python/)
- **Server:** [Uvicorn](https://www.uvicorn.org/)
- **Containerization:** [Docker](https://www.docker.com/)
